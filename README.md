## 📚 Apa Itu PPLG?

**PPLG** adalah singkatan dari **Pengembangan Perangkat Lunak dan Gim**.

PPLG merupakan bidang keahlian yang mempelajari proses **merancang, membuat, mengembangkan, menguji, dan memelihara perangkat lunak serta gim**.

---

## 🎯 Tujuan Mempelajari PPLG

- 💻 Memahami dasar-dasar pemrograman
- 🧠 Melatih kemampuan berpikir logis
- 🌐 Membuat website
- 📱 Mengembangkan aplikasi
- 🎮 Membuat gim sederhana
- 🗄️ Memahami database
- 🔧 Meningkatkan kemampuan problem solving
- 🚀 Mengembangkan kreativitas
